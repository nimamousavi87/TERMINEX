## ✨ درباره TERMINEX

TERMINEX یک ابزار چندمنظوره نوشته‌شده با Python است که برای بررسی شبکه، اطلاعات سیستم، ابزارهای امنیتی و امکانات برنامه‌نویسی طراحی شده است.

## 🌐 ابزارهای شبکه

- نمایش IP محلی
- بررسی اتصال اینترنت
- ابزار Ping
- بررسی وب‌سایت
- جست‌وجوی DNS
- بررسی گواهی SSL

## 💻 ابزارهای سیستم

- اطلاعات سیستم‌عامل
- اطلاعات فضای ذخیره‌سازی
- اطلاعات Python

## 🔐 ابزارهای امنیتی

- تولید رمز عبور امن
- بررسی قدرت رمز عبور

## 🛠 ابزارهای توسعه‌دهندگان

- نمایش نسخه Python
- نمایش تاریخ و ساعت
- اطلاعات محیط اجرا

## 📥 نصب و اجرا

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/nimamousavi87/TERMINEX.git
```

وارد پوشه شوید:

```bash
cd TERMINEX
```

برنامه را اجرا کنید:

```bash
python main.py
```

- Linux
