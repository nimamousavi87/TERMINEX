## ✨ درباره TERMINEX

TERMINEX یک ابزار چندمنظوره و چندسکویی نوشته‌شده با Python است که برای عیب‌یابی شبکه، نمایش اطلاعات سیستم، ابزارهای امنیتی و امکانات برنامه‌نویسی طراحی شده است.

## 🌐 ابزارهای شبکه

- نمایش IP محلی
- بررسی اتصال اینترنت
- ابزار Ping
- بررسی دسترسی وب‌سایت
- جست‌وجوی DNS
- بررسی گواهی SSL

## 💻 ابزارهای سیستم

- نمایش اطلاعات سیستم‌عامل
- نمایش اطلاعات فضای ذخیره‌سازی
- نمایش اطلاعات Python

## 🔐 ابزارهای امنیتی

- تولید رمز عبور امن
- بررسی قدرت رمز عبور

## 🛠 ابزارهای توسعه‌دهندگان

- نمایش نسخه Python
- نمایش تاریخ و ساعت
- نمایش اطلاعات محیط اجرا
