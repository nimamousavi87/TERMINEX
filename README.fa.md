## ✨ درباره TERMINEX

TERMINEX یک ابزار چندمنظوره و چندسکویی نوشته‌شده با Python است که برای عیب‌یابی شبکه، نمایش اطلاعات سیستم، ابزارهای امنیتی و امکانات توسعه‌دهندگان طراحی شده است.

## 🌐 ابزارهای شبکه

- نمایش IP محلی
- بررسی اتصال اینترنت
- ابزار Ping
- بررسی دسترسی وب‌سایت
- جست‌وجوی DNS
- بررسی گواهی SSL

## 💻 ابزارهای سیستم

- نمایش اطلاعات سیستم‌عامل
- نمایش اطلاعات فضای ذخیره‌سازی
- نمایش اطلاعات Python

## 🔐 ابزارهای امنیتی

- تولید رمز عبور تصادفی امن
- بررسی قدرت رمز عبور

## 🛠 ابزارهای توسعه‌دهندگان

- نمایش نسخه Python
- نمایش تاریخ و ساعت
- نمایش اطلاعات محیط اجرا

## 📦 آموزش نصب و اجرا

### پیش‌نیازها

- Python 3
- Git
- اتصال اینترنت برای دریافت پروژه

### 📱 نصب در اندروید (Termux)

ابتدا بسته‌های Termux را به‌روزرسانی کنید:

```bash
pkg update && pkg upgrade -y
```

سپس Python و Git را نصب کنید:

```bash
pkg install python git -y
```

دریافت پروژه:

```bash
git clone https://github.com/nimamousavi87/TERMINEX.git
```

ورود به پوشه پروژه:

```bash
cd TERMINEX
```

نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

اجرای برنامه:

```bash
python main.py
```

### 🪟 نصب در ویندوز

۱. ابتدا Python 3 و Git را نصب کنید.

۲. برنامه CMD یا PowerShell را باز کنید.

۳. دستور دریافت پروژه را اجرا کنید:

```bash
git clone https://github.com/nimamousavi87/TERMINEX.git
```

۴. وارد پوشه پروژه شوید:

```bash
cd TERMINEX
```

۵. وابستگی‌ها را نصب کنید:

```bash
python -m pip install -r requirements.txt
```

۶. برنامه را اجرا کنید:

```bash
python main.py
```

### 🐧 نصب در لینوکس

ابتدا Python 3 و Git را با ابزار مدیریت بسته توزیع لینوکس خود نصب کنید.

سپس دستورات زیر را اجرا کنید:

```bash
git clone https://github.com/nimamousavi87/TERMINEX.git
cd TERMINEX
python3 -m pip install -r requirements.txt
python3 main.py
```

## 🔄 به‌روزرسانی TERMINEX

برای دریافت آخرین تغییرات پروژه، وارد پوشه TERMINEX شوید:

```bash
cd TERMINEX
```

سپس اجرا کنید:

```bash
git pull origin main
```

برای اجرای مجدد:

```bash
python main.py
```

در لینوکس در صورت نیاز:

```bash
python3 main.py
```
